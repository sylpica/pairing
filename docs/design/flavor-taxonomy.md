# 香味分類体系（独自設計 v1）

## 方針
- お茶とチョコレートを比較できる「共通分類」とする。
- 参考枠組み: 茶VOC総説（Zeng et al. 2025, Foods 14:2574）の化学分類と茶類別香りの整理、ファインフレーバーカカオ系統的レビュー（Putri et al. 2024, J Food Sci 89:1917-1943）の記述語彙（caramel / fruity / floral / malty / nutty / spicy 等）。
- 既存のホイール図は複製しない。本分類は上記語彙を一般利用者向け日本語に再編した独自体系であり、各細分類は「身近な香りの例」で説明する。
- 分類は香り（アロマ）専用。味覚（甘・酸・苦・うま）と渋味（口腔感覚）は別グラフで扱い、混ぜない。

## 強度
弱い / 普通 / 強い の順序尺度 + 不明（データなし）。数値化しない。

## 運用ルール
- 細分類への強度付与は、出典（論文ID）と根拠区分（原著測定 / 官能評価 / 総説整理 / 一般分類特徴）を必ず伴う。
- 根拠のない細分類は「不明」のままにする（弱いと誤認させない）。
