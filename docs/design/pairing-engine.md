# ペアリング予測エンジン仕様 v1（ルールベース）

## 科学的根拠と限界（正本）
Spence (2020, Food Research International 133:109124) の批判的総説が示すとおり、共有香味分子に基づく food-pairing 仮説は支持されておらず、成分の単純合算で知覚を予測することはできない。したがって本エンジンは「相性」を予測・採点しない。

## すること
入力: お茶とチョコの FlavorProfile（強度は順序尺度）。
出力:
1. 共通する香味（両方で normal 以上、同じ細分類または大分類）→「調和の候補」として提示。区分は原則 exploratory（直接の官能研究がある組合せのみ measured/general に昇格し、出典を付ける）。
2. 対照的な特徴（一方に強く他方にない大分類、味覚の対比 例: 一方の酸味×他方の甘味）→「対比の候補」として提示。効果（引き立つ等）は断定せず「〜と感じる場合がある／未検証」の表現に限定。
3. 味覚・渋味の並置表示（計算で合成しない）。
4. 推定ホイール: 合算しない。共通＝両輪の重なり表示、対比＝並置マーカーのみ。予測できない項目は描かない（不明）。

## しないこと
- 数値スコア、順位付けの断定、成分量の加算、強度の比例計算。
- 出典のない「変化」の断言。

## 区分の決め方（決定的ルール）
- 組合せ自体の直接研究（source に pairing 対象として登録）がある → measured
- 片側または両側の根拠が茶類・種別レベルの一般知見のみ → general の説明 + 個別組合せとしては exploratory と併記
- プロファイルの unknown 率が高い（共通判定に使える note が不足） → insufficient（結果を出さず不足を表示）

## 検証ケース（テスト）
指示書§15.2のケースを unit test 化: 根拠あり/一般のみ/不足/香味が多い/大きく異なる/極端なカカオ含有率 等。
