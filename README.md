# お茶×チョコレート フレーバー図鑑＆ペアリングシミュレーター

科学論文に基づいて、お茶とチョコレートの香りを探索できる無料Webアプリです。
ログイン不要・インストール不要で、URLを開くだけで使えます。

## できること
- お茶を調べる：茶類・製法ごとのフレーバーホイール、味覚グラフ、関連する香り成分と出典論文
- チョコを調べる：種類・焙煎ごとのフレーバーホイールと出典
- 組み合わせる：共通する香り（調和の候補）と対比する特徴（対比の候補）を、根拠の区分つきで表示
- 茶類・製法の比較：同一生葉から作った6茶類の原著研究の紹介と比較ホイール
- お気に入り・履歴（端末内保存）、JSONでの書き出し・復元

## 科学データの方針
- 表示する香味は査読済み論文で確認できる範囲のみ。根拠のないデータは作らず、「不明」「情報不足」と表示します。
- 香りの強さは「弱い／普通／強い」の3段階のみで、数値的な精度を装いません。
- ペアリングは香りを足し算したり相性を点数化したりしません。共通点と対比を「探索的な予想」として示し、実際に組み合わせた官能評価とは区別します（根拠：Spence 2020 の批判的総説）。
- 論文の文章・図表は転載していません。出典はアプリ内の「出典・論文一覧」と docs/research/ で確認できます。

## 収録範囲（初期版）
- お茶 14件（緑茶の製法4種、白茶、黄茶、烏龍茶、紅茶、黒茶、煎茶、抹茶、玉露、ほうじ茶、鳳凰単叢）— 総説・原著に基づく一般的特徴（品種固有の実測ではない）
- チョコレート 5件（焙煎ダーク、未焙煎ダーク、ファインフレーバーカカオ、ミルク、ホワイト）— ミルクは原著に基づく一般レベル、ホワイトはモデル系研究に基づく説明（市販品の実測ではない旨を明記）
- 香味成分 17件、出典論文 17件（全件実在を検証済み）
- 品種固有・商品固有のプロファイルは未収録（原著確認が取れたものから追加します）

## 開発
```bash
npm install
npm run dev     # 開発サーバー
npm test        # 単体テスト（データ整合性・ペアリングエンジン・保存形式）
npm run build   # 本番ビルド（dist/）
```
データの追加・更新手順は docs/DATA_GUIDE.md、公開手順は docs/DEPLOY.md を参照してください。
設計文書は docs/design/、要件は docs/REQUIREMENTS.md にあります。
